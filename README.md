# AIgnite Exercise FTUI Hardware Bootcamp

## Description
This repository documents my learning journey in a hardware workshop conducted over four weeks.  
Each week focused on a different foundational topic, gradually building skills in electronics, programming, IoT, and AI integration.

## Workshop Structure

### Week 1 – Basic Electronics
- Introduction to basic electronic components
- Understanding voltage, current, and circuits
- Hands-on practice with simple ESP-based circuits
- **Wokwi project link: https://wokwi.com/projects/445129392175455233**

### Week 2 – Programming Fundamentals
- Introduction to programming using Arduino IDE
- Writing basic programs for ESP
- Controlling LEDs, motors, and basic inputs/outputs
- **Wokwi project link: https://wokwi.com/projects/445337446998872065**

### Week 3 – Internet of Things (IoT)
- Connecting ESP to Wi-Fi
- Integrating ESP-based IoT projects with Blynk
- Sending and receiving data over the internet
- Building simple IoT applications
- **Wokwi project link:
https://wokwi.com/projects/445853127126678529
https://blynk.cloud/dashboard/908791/global/devices/1/organization/908791/devices/3578594/dashboard**

### Week 4 – IoT with AI (Gemini Integration)
- Introduction to AI in IoT systems
- Integrating ESP-based IoT projects with Blynk and Google Gemini
- Using AI to process data and enhance system intelligence
- **Wokwi project link: https://wokwi.com/projects/446495095538344961**
